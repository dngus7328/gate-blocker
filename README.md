# 프로젝트명 미정

플래피버드식 구조를 역발상한 HTML5 기반의 캐주얼 액션 게임입니다.

플레이어는 캐릭터를 직접 움직이는 대신, 화면의 **위·아래 장애물 세트**를 조작합니다.
다가오는 적들이 장애물 사이의 통로를 빠져나가지 못하도록 위치를 조절해 충돌시키는 것이 기본 목표입니다.

---

## 게임 핵심

* 위쪽과 아래쪽 장애물은 **항상 동시에 움직입니다.**
* 장애물 사이의 통로 크기는 기본적으로 고정됩니다.
* 플레이어는 통로의 위치를 위아래로 이동시킬 수 있습니다.
* 적이 장애물에 충돌하면 점수를 얻습니다.
* 적이 통로를 빠져나가면 패널티를 받습니다.
* 진행될수록 여러 적이 동시에 등장합니다.
* 적마다 이동 속도와 움직임 패턴이 달라질 예정입니다.
* 강화 아이템을 통해 장애물의 이동 속도 등을 강화할 수 있습니다.

---

## 조작

| 입력    | 동작            |
| ----- | ------------- |
| W / ↑ | 장애물 세트 위로 이동  |
| S / ↓ | 장애물 세트 아래로 이동 |

조작 방식은 개발 과정에서 변경될 수 있습니다.

---

## 개발 방향

이 프로젝트는 기능 추가와 밸런스 수정이 쉽도록 가능한 한 **하드코딩을 줄이는 구조**로 제작합니다.

적, 아이템, 스테이지, 게임 설정 등의 수치는 각 시스템의 코드 안에 직접 작성하지 않고 별도의 데이터 파일에서 관리하는 것을 기본 원칙으로 합니다.

예:

```text
js/
├─ core/
├─ entities/
├─ managers/
├─ data/
└─ scenes/
```

### 역할

* `core`
  게임 전체 실행, 입력 등 핵심 시스템

* `entities`
  장애물, 적, 아이템 등의 게임 오브젝트

* `managers`
  적 생성, 충돌, 아이템 등 각 시스템 관리

* `data`
  적 능력치, 아이템 효과, 스테이지 설정 등의 데이터

* `scenes`
  타이틀, 게임, 결과 화면 등 게임 진행 상태

---

## 현재 개발 단계

초기 프로토타입 제작 단계입니다.

우선 다음 기능부터 구현합니다.

1. 기본 게임 화면
2. 위·아래 장애물 동시 이동
3. 적 생성 및 이동
4. 장애물과 적의 충돌 판정
5. 적 통과 판정
6. 점수 시스템
7. 게임 오버 및 재시작

이후 기본 플레이가 재미있는지 확인한 뒤 적 종류, 난이도 상승, 아이템 및 강화 시스템을 추가할 예정입니다.

---

## 목표

복잡한 조작보다 **다가오는 적의 위치와 움직임을 보고 통로의 위치를 순간적으로 판단하는 재미**를 중심으로 합니다.

초반에는 단순하게 시작하지만, 여러 적과 서로 다른 움직임 패턴이 동시에 등장하면서 점차 판단이 어려워지는 구조를 목표로 합니다.
